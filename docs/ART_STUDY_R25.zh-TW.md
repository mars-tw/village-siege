# R25：AoE III 與開源 RTS 視覺／玩法研究

研究日期：2026-10-01。以下來源已實際讀取；第三方圖像只作參考，不納入素材包。

[AoE III DE 開發訪談](https://www.ageofempires.com/news/interview-joss-ellis/)說明地形材質融合、河流、拉遠戰場、資訊化介面、攻擊警示與陣營辨識。其卡組／補給及升階選擇讓玩家依文明優勢與對局時機調整策略。這輪採取的具體方向是改善河岸與道路過渡、人物比例、命令圖示、戰場視野與戰鬥／生產完成回饋；檢查是否過早的計時勝利壓縮了發展與攻城。

[0 A.D. 官方特色](https://play0ad.com/game-info/features/)提供開源 RTS 對照：文明的外觀和玩法應一致，真實地理植被構成地圖，科技選擇有代價。這輪要保持三聚落的地形辨識與合法格位，將裝飾放在可讀通行資訊之外；人物縮小後仍須可辨識，不能以塞滿裝飾取代戰術層次。

## 正式場景設計

松綠 #243e31、胡桃木 #493526、黃銅 #c7a66a、羊皮紙 #ead9af、溪水 #547d89、赤赭 #ad5143。地形保持低對比，陣營／選取和技能命中才使用高對比色。Georgia／Noto Serif TC 作有限標題，Segoe UI／Noto Sans TC 作操作，Consolas 只用於數字。

署名元素是原創「邊境指揮盤」：真兵種或材料的點陣圖示、清楚的文字與付費成本，取代大部分抽象文字字形。房屋是村莊尺度基準，步兵高度約半個房屋門樓，騎兵與大型攻城物再依剪影加大。保留真六方向與動作影格，調整的是呈現尺度及辨識。

遊戲採既有等角 2D 引擎。本輪的 AoE III 目標是可讀性、場景層次和策略體驗；不得把這些改動說成已重建其 3D 引擎、物理或同等內容量。補給與其他新規則只有真正接入權威模擬並驗證後才列為交付。
