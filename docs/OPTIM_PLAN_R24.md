# R24：玩家可完成的公開單機版

2026-10-01。以完整玩家操作驗收公開Web／PWA小型RTS；Android／iOS簽署App與公開多人服務不列為本次已交付功能。

## 必須完成

- 合法有限資源足以完成兩次時代升級、七科技、七兵種及防守；不靠改錢、停AI或強制勝利驗證。
- 解決友軍卡路、偵察後存檔／重播不一致、外怪點擊無法攻擊與誤退出。
- 常駐「科技與時代」入口：顯示升階、缺少建築、材料、研究前置、佇列及完成狀態，能直接前往對應操作。
- 保存目前戰局並可續玩，舊存檔先驗證再明確移轉到新規則；保留原檔與已採資源／已付材料。
- 真實UI驗證升階、全部研究、生產／七技能、外怪交戰、四勝途、勝敗與再戰，桌機及觸控版面均可達。
- 全部既有測試、正式包、授權／秘密／預算與CI通過；只在實測完成後標示1.0公開單機版。

## 八面向與範圍

角色、地表與建築沿用R22點陣圖，不使用SVG或另生占位美術。檢查實際場景的一致性、角色剪影及真影格；修正離線影格更新時序。科技面板採同一套松綠／銅色介面，控制至少44CSSpx，矮視口分頁、不長捲動、關閉可達。建造、採集與戰鬥動線由共享格位規則驗證，技能只在權威命中／合法指令後生效。性能量測說明場景、裝置與模擬限制，不把單一暖機案例當所有手機保證。
