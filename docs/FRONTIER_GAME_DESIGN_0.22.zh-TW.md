# Village Siege 0.22 邊境村落遊戲設計

0.22把開局改為可擴張的村落：一座議事堂、三名工匠和三種資源。玩家自己興建兵營、選擇通道、組織軍隊，再以攻城或控制地標取得勝利。地圖擴為32×24格，移除原先包住村莊的預建圍牆與箭塔，讓經濟、訓練和行軍能在同一片可讀的空間進行。

本文件描述這輪實際規則、操作與素材契約。角色素材的核准與送入runtime狀態，以`combatAnimationManifest.ts`、`villageWorkerAnimation.ts`及release asset manifest為準；完整美術審核、真機驗證與發布結果另見當輪交付報告。

## 三張地圖的分工

| 地圖 | 空間與路線 | 玩家取捨 | 聚落規則 |
|---|---|---|---|
| 松林堡 `pinehold` | 林緣包圍開放草地；中央有短河段，北／中／南各有3格寬通道 | 穩定採集、混兵守路，也可沿南北繞行偵察；森林裝飾不把村莊封起來 | 採集倍率1.03；建築耐久倍率1.06 |
| 河谷鎮 `riverstead` | 河流縱貫地圖；北、中、南各有3格寬渡口，南路比另兩圖稍靠下 | 快速轉線與運輸有效率，但擴張時須照顧跨河路徑；不能把房屋蓋在保留渡口 | 單位移速倍率1.03；搬運上限倍率1.10，實際整數上限依shared計算 |

三張地圖都是32×24格、2:1等角投影，邏輯格以96×48世界像素呈現。`W`水面與`R`岩地不可通行；`G`草地、`M`土岸、`S`道路、`T`林地裝飾可通行。保留通道可走、不可蓋建築，避免把唯一跨河或山路永久封住。真正的木材資源節點另外占格，不能把裝飾樹與可採木材混為一談。

標準雙人開局西方議事堂在`(4,11)`，東方在`(26,11)`，各為2×2格。兩方相距22格，開局不直接看見敵方家園；中央控制點在`(16,12)`，半徑3格。

兩側都保留住宅、倉儲與軍事建築空地。三種資源分開放置，每個節點有可抵達的工作接近格；議事堂周圍有多個卸貨／產兵出口。標準開局沒有預建兵營、塔、牆或門，畫面上的這些建築應來自實際建造。

三至五陣營的相容模式採各自合法出生點配置，未以本文件的標準雙人開局完整局證據代替多人驗收。

## 玩家實際開局

起始資源為糧食420、木材420、石礦260，人口3／10。三名工匠已分別朝糧食、木材、石礦工作；玩家仍可重新分配、手動卸貨、修理或施工。搬運必須送到有效卸貨點才入帳，介面不自行增加資源。

木材節點有1000，石礦700，糧食360。木材與石礦耗盡後移除；糧食耗盡後休耕30秒再復育，休耕中的節點仍占格。建築與資源之間留走道，特別是兵營出口、卸貨格與軍隊集結點。

一個已由真指令走通的開局如下；座標是可重現範例，玩家可在其他合法空地建造。

1. 重新指定三名工匠採集三種資源，確認有實際卸貨。
2. 使用一名工匠在`(6,8)`建造家屋，人口上限從10增至18。
3. 同一名工匠在`(7,13)`興建兵營，完工後回到經濟工作。
4. 兵營集結點設在`(12,12)`的開放區，訓練一名盾牌手與四名戰士。
5. 集結後施放盾牆，向中央`(16,12)`移動，守住目標並用收入補充兵力。
6. 可見敵人靠近控制點時直接交戰；清除威脅後重新佔位，直到合法終局。

這條路線證明開放村落能完成「經濟→建造→訓練→技能→交戰→勝利」。它不代表唯一解，也不表示所有村莊、AI性格與兵種組合已完成平衡調整。

## 所有玩家角色與混編

工匠 `villager` 從議事堂訓練，負責採集、搬運、建造與修理。工匠有專屬圍裙／工具造型與工作影格契約，戰鬥數值與軍事單位不同；選取工匠時顯示採集、卸貨與建造指令。

技能依類型採自身、實體、地面或方向選點。玩家需看清目標與範圍；取消選點、被拒絕的指令不會在畫面自行施放。盾牆、衝鋒與架設具有方向／位置意義，混編與站位比單純堆同一兵種更重要。

## 四條合法勝途

| 勝途 | 達成方式 |
|---|---|
| 議事核心征服 | 對方完成的議事堂全部失守後，若60秒重建寬限內沒有恢復有效議事堂，該隊被淘汰 |
| 全軍殲滅 | 對方失去shared規則定義的有效戰力／生存據點後判定；不把單一動畫消失當作殲滅 |
| 拓界銅標 | 至少一座有效完工銅標持續存在90秒；施工中的銅標不累計 |
| 中域控制 | 開局60秒後，在`(16,12)`半徑3格區域無敵方隊伍爭奪時，累計控制120秒 |

中域計時採累計控制，離開或被爭奪時停止增加，現有進度不自動歸零；銅標的持續控制在條件失效時重置。同tick多條勝途與和局由shared規則統一結算。終局只出現一次，結果提供再戰、重播與返回入口。

## 操作與畫面職責

電腦提供點選／多選／框選、右鍵移動或攻擊、WASD鏡頭、滾輪縮放、B建造、P暫停與Esc取消／返回。手機和平板提供點選單位後下令、拖曳鏡頭、縮放與固定指令列；戰場以橫向為主要操作方式。

底部七格依選取物改變：工匠有採集／卸貨／建造，建築有訓練／研究／佇列／集結，軍隊有攻擊移動／巡邏／編隊／姿態／技能／停止。建造、技能與集結選點都需有可取消路徑；控制區不應與世界物件互相攔截。

上方顯示資源、人口、主要勝利進度；選取物顯示名稱、生命、工作或技能資訊。小地圖僅依玩家可見／已探索資料呈現，不洩漏黑霧後的即時敵情。初始HTML先提供載入狀態，真正啟動失敗提供瀏覽器訊息和手動修復；戰場素材載入期間有進度與返回選單，不留一片看似當掉的空白。

教學共有採集卸貨、升階、研究、探索、交戰、摧毀敵建築、合法勝利七個目標。各目標根據玩家接受過的命令與真實結果認領，不贈送資源或打開黑霧。開放地圖不再要求找一座不存在的預建城門。
