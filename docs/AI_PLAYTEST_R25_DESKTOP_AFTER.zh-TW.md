# R25 修改後 AI 實玩：新玩家／桌機

- 版本：本機整合版 `1.1.0`（`http://127.0.0.1:5174/`）
- 視窗：`1280×720`
- 模式：預設「攻城戰」，均衡 AI，標準難度
- 實玩時段：2026-10-01 18:39:30 開戰；第一段連續玩到 18:48 之後手動重載，已超過 8 分鐘。隨後又開新局覆驗按鈕雙派送修正、存檔匯出／重載／匯入與戰前選單。
- 操作約束：所有採集、建造、訓練、選單、存讀都經由真實 pointer／keyboard 與畫面按鈕完成；沒有使用 `issue`／`step`／state grant，也沒有匯入他人或已付費 checkpoint。

## 結果先說

修改後的發展因果比 1.0 好懂。我可以把三名工匠分成採糧、伐木、採石，放下第一座兵營，點主城管理而不把施工工匠調走，並在第一波前造出戰士。建築完工、時代升級、敵軍來襲都有比原版明顯的訊息。

不過，標準難度仍然很壓迫。第一段實玩中，我有兵可守，但還是在兩波壓力下失去戰士與主城。攻城戰沒有因中域控制而提早結束，所以我實際多做了工匠復工、兵營補兵、城寨升級與存檔操作；這確實比原版更像一場完整戰役。

## 我實際操作的路徑

1. 戰前先在「攻城戰」與「領土爭奪」之間切換，確認描述與底部 readout 同步，再選回預設攻城戰開局。
2. 開啟「工匠分工」，將工匠 1 指派採糧、工匠 2 伐木、工匠 3 採石。面板後續顯示「攜帶糧 12/12」、「攜帶木 12/12」與「攜帶石 4/12」。
3. 用工匠 3 在主城旁選擇綠色工地放置邊軍兵營，第一次就被接受。
4. 施工中左點主城，底部正確切到主城的工匠訓練、研究、佇列與集結點；施工工匠仍留在兵營旁建造。
5. 兵營完工後訓練戰士。第一段實玩發現修正前的 DOM proxy 單次 role click 會讓佇列從 0/5 跳到 2/5；回報後重載整合修正，再測為單次 0→1，兩次點擊 0→1→2。
6. 選工匠 2 蓋木作營，接著升級城寨期。畫面出現「木作營完工」與「城門銅鐘響徹村道｜聚落邁入城寨期」。
7. 敵襲時確認頂部大型「敵軍來襲！查看受損單位並調兵防守」訊息，也在戰後看到「戰士已失守」、「村鎮議事堂已失守」。
8. 修正 DOM proxy 後，由系統選單匯出自己當前的 `.vssave`，手動 reload，再由畫面匯入同一份存檔。匯入後畫面回到人口 6/10、兵營與戰士都在場、敵軍攻勢逼近的進度。

## 改善後的體驗

### 工匠分工

這是這輪最有感的改善。原版的「全選工匠→點某一種資源」很容易讓三人全部改同一件工作。現在每人有獨立卡片與「選取／採糧／伐木／採石」，而且能看到運送與攜帶量。我第一次可以直接說出「一糧、一木、一石」的發展方案，不需要靠地圖上重疊的工匠猜誰在做什麼。

仍有一個小摩擦：剛指派完時，三張卡都只寫「採集中·未攜帶材料」，要等它們真正拿到資源，才會從「攜帶糧／木／石」看出個別分工。若卡片直接留一個「目標：伐木」標示，因果會更即時。

### 建造、管理與通知

- 主城旁空地的綠色 footprint 很明確，點下後一次接受。這次沒有重複遇到 1.0 那種「看似空地，點了才說被物件占用」。
- 施工中點已完工的主城，顯示的是建築管理指令，沒有把施工工匠拉回去。這讓「選建築管理」與「送材料給工地」的操作邊界容易預期。
- 「木作營完工」及升時代文字有具體事件，不再只靠建築外觀與科技前置側面猜測。
- 「敵軍來襲」對我的動作有實際影響：我會立即停止開科技面板，轉去看迷你地圖與全選軍隊。這比 1.0 只在小字顯示「攻勢逼近」強很多。

### 戰前模式與控制尺寸

- 「攻城戰」預設選中，文字直接說明只靠議事堂與殲滅分勝負。「領土爭奪」則列出四條勝途。切換後按鈕、描述和底部 readout 同步。
- 兩個模式按鈕在 1280×720 實測分別約 `226.4×44 CSS px`。戰中的「工匠分工」為 `96×48 CSS px`，戰士訓練按鈕為約 `91.8×96.8 CSS px`。
- 戰前選單在 1280×720 內完整顯示，選擇聚落、模式、AI 風格、難度、開始與次要按鈕不需要捲動。

## 仍然需注意的問題

1. **標準難度容錯率仍低。** 我比 1.0 更早造出兵，還是在第二波前後失去主城。改善了「知道自己為什麼輸」，但不等於新玩家已經容易存活。
2. **單次 DOM role click 曾雙派送。** 修正前，兵營 0/5 在一次點擊後直接變 2/5。整合修正後已重測為一次就 1，兩次才 2。報告保留修正前的真實經過，沒有把它改寫成一開始就正常。
3. **存檔成功後的訊息容易被盤面狀態覆蓋。** 匯入自己的 save 後，畫面很快又顯示「無法自動存檔」與「敵軍攻勢逼近」。我是回到戰場看到人口 6/10、兵營、戰士與攻勢位置都復原，才確認讀檔完成。
4. **工匠卡片剛改工作時還不顯示目標資源類型。** 需等攜帶量出現後才能二次確認。

| 項目 | 公開 1.0 | 本機 1.1 | 根據 |
| --- | ---: | ---: | --- |
| 娛樂度 | 5/10 | 7/10 | 修改後有明確的經濟分工、守第一波、造兵、升時代與存讀循環；等待時段仍存在。 |
| 操作因果清楚度 | 4/10 | 8/10 | 個別工匠、footprint、建築管理、完工與敵襲通知都能在 UI 裡找到對應。 |
| 戰鬥可讀性 | 5/10 | 7/10 | 新大型敵襲訊息有效，單位與迷你地圖較好讀；敵方攻擊具體目標仍需看血條和現場。 |
| 戰前理解 | 6/10 | 8/10 | 兩個模式的勝利條件直接列出，且預設攻城戰與 readout 一致。 |

這些是一次 AI 體驗的主觀比較，不是人類玩家調查。我也不把這個原創網頁 RTS 寫成已經等同《世紀帝國 III》；這次只能說它比 1.0 更接近「可以規劃經濟、讀懂壓力、再做攻守取捨」的體驗。
