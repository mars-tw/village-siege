# R25：AI 體驗與世紀帝國 III 品質目標

2026-10-01。基準為公開 1.0.0／commit 90e2a412；保留原創世界與不使用 SVG 的要求。本輪要交付實際遊玩報告、依觀察修改的遊戲，以及修改後的再次體驗。

## 體驗方法

三個獨立 AI 上下文以新玩家、策略玩家與視覺／觸控玩家身分實際操作公開遊戲。各用自己命名的瀏覽器；先觀察畫面，再用滑鼠、鍵盤代理或觸控下令，不增加資源、停 AI、改狀態或以內部命令冒稱實玩。紀錄實際經過時間、玩法選擇、勝敗或中斷、卡點與截圖。娛樂度是 AI 體驗判斷，不能冒稱真人調查。

## 八面向與交付閘門

| 面向 | 本輪驗收 |
| --- | --- |
| 美術 | 以 AoE III 的地形層次、比例、陣營與物件可讀性為參考；先研究官方資料及開源 RTS 技法，再調整正式場景。原創 PNG／WebGL，沒有佔位 SVG。 |
| 按鈕 | 桌機、矮筆電、手機和平板控制可達，至少 44 CSS px，重要控制不互遮。 |
| 選單 | 戰前選擇與戰中管理直接影響玩法；返回、關閉始終可達，不強迫長捲動。 |
| 人物 | 工匠、步兵、遠程、騎兵、攻城兵比例與剪影分明，不比房屋巨大；選取與陣營辨識清楚。 |
| 地圖 | 草地、道路、河岸、林地與建造基地有連續層次；裝飾不掩蓋合法通行與戰鬥資訊。 |
| 技能 | 兵種角色、施放、命中與冷卻清楚；觸控可取消，指令與共享規則一致。 |
| 角色外觀 | 真圖集、實際縮圖與不同方向檢查；沿用原創素材並改善取樣、比例及亮度，缺件誠實記錄。 |
| 動作 | 保留真影格姿勢；操作與戰鬥回饋匹配權威事件，不用單圖晃動冒充。 |

娛樂度修改以體驗證據決定：優先解決等待、無目的操作、過早自動終局、兵種取捨與戰鬥回饋。AoE III 的補給、發展選擇與地圖爭奪作為設計標準，不假稱已完成同等規模 3D 引擎或完整商業遊戲內容。

完成後獨立再玩，檢查舊檔、教學、科技、生產、施工、技能、勝敗與續玩；執行適當回歸、正式包／授權／秘密掃描、版本更新與 CI。效能在其他體驗停止後獨立量測三次，區分桌機、觸控模擬與實機。before／after 三視口、實玩報告與 R25 交付紀錄保存於 docs/evidence/r25；私有存檔與日誌留在 .audit-tmp/r25。
