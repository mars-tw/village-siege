# 0.22 人物與地圖重製交付

2026-10-01。這輪替換實際戰場的工匠、七兵種、三外怪、自然物與地表。工匠、戰士、槍盾兵、弓箭手共24張獨立六向動畫表；另外四兵種與三外怪各24格單向動畫，沒有假稱完整六向。原始圖、提示詞、裁格與最終雜湊在`docs/art/frontier`，正式執行只帶壓縮後的素材。

松林堡、河谷鎮、高地寨改成32×24開放村落。從一座主城與三工匠起步，保留採集、擴建、出營和集結空間，中央渡口／隘口與側翼外怪提供進攻選擇。地表按真正通行格位繪製，素材均為PNG／WebP，不使用SVG。完整角色與地圖設計見[0.22遊戲設計](FRONTIER_GAME_DESIGN_0.22.zh-TW.md)。

桌機修正資源／目標文字重疊、人物透明點擊區攔住資源，以及擴大地圖後仍限制17／15的點選邊界；三種資源圖案中心均以實際滑鼠點擊選中。人物持續播放行走與工作影格，朝向遵循權威狀態；手機選取資訊集中在指令列，避免多人名稱與貨物標記重疊。

`npm run verify`通過471項測試（client126、server86、shared238、ops21），31張實際執行動畫表通過影格／透明邊界／跨表重用檢查。素材與相依授權、秘密掃描、正式建置及執行包閘門通過：35個美術檔7,321,143bytes，完整執行包約9.68MB；保留原16MiB美術／20MiB執行包預算。

正常標準均衡AI的Runtime驗證完成採集、家屋與兵營施工、12名軍人訓練、技能、探索、交戰及279.5秒中域勝利；28條玩家命令全接受，重播一致，再戰回到正常開局。另一次真正瀏覽器場景執行15條有效命令後，讓遊戲自然繼續，到274.5秒取得中域勝利；沒有改資源、AI或勝負狀態，顯示勝利、再戰、重播與返回。

正式執行包在1440×900電腦、844×390手機觸控及1024×768平板視口開局成功。手機以真正touchscreen事件選工匠、伐木、選家屋並在空地開始施工；這些是Chromium裝置模擬，沒有冒稱完成真機整局或原生App驗收。PWA經明確下載後，在網路關閉時重新整理並成功進入實際戰場。暖機桌機120個影格間隔p95為16.8ms，量測場景只有三名工匠，沒有當作所有戰局或手機效能保證。

驗證原始摘要在[browser-validation.json](evidence/r22/browser-validation.json)、[open-village-playthrough.json](evidence/r22/open-village-playthrough.json)與[worker-animation-probe.json](evidence/r22/worker-animation-probe.json)。完整權威journal／replay只留本機，未加入公開資產。

Android／iOS原生App、另外七組角色六向、完整戰役及公開多人服務仍依[更新路線](REBUILD_ROADMAP_2026-09-30.zh-TW.md)後續製作。本輪規則為`village-siege/0.19.0`，舊版存檔保留原檔並以版本檢查拒絕匯入，不做未驗證的自動轉換。
