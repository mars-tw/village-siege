# R27：實玩錄影與遊戲內影片

2026-10-02。基準 App 1.2.0／ee623082。使用者授權實際錄影、遊戲內體驗入口及開源發布，不使用 SVG。

## 交付

1. 真瀏覽器正常操作錄製採集／建造、科技／軍隊與移動／交戰短片；可透過正常介面接續自己已完成的戰局，明示讀檔來源，禁止免費資源、改時鐘或私有指令。
2. 遊戲新增可關閉的「實玩影片」原生播放器，桌機與觸控可切片、播放／暫停／拖曳，不自動播放或首次進場下載整部影片。
3. MP4 H.264 影片、PNG/WebP 封面、繁中逐段說明與來源／SHA-256 放入 repo。保持原有 runtime 容量守門；影片按需載入，離線戰役下載不強迫包含影片。
4. 原始錄影保留本機；產物實際解碼、黑畫面與凍結檢查，依核心規則由地端模型裁決影片內容品質，獨立上下文覆核接線與玩家操作。

## 八面向驗收

| 面向 | 本輪驗收 |
| --- | --- |
| 美術 | 使用真實遊戲原創美術，不以模擬畫面冒充操作。 |
| 按鈕 | 影片入口、切片、關閉與主要播放控制可達，產品按鈕至少 44 CSS px。 |
| 選單 | 1366×600／1024×768／844×390／667×375 保留開始與繼續入口；播放器無關閉死路。 |
| 人物 | 錄影中保留角色、旗幟與正常選取／生命顯示，不變更尺度。 |
| 地圖 | 影片來自可見實際戰場，明示片段場景與進度，未洩漏霧外實體。 |
| 技能 | 出現在影片的命令使用正常手勢，文字不承諾未展示內容。 |
| 外觀 | 原生播放器搭配既有木色／軍綠介面，影片維持比例與可讀畫面，不拉伸。 |
| 動作 | 原始實錄，至少展示移動、停止與轉向；不以仍圖位移代替遊戲動畫。 |
