# v0.21.1 遊戲入口修復

日期：2026-10-01。起因是使用者回報桌機瀏覽器無法進入遊戲。

## 重現

公開0.21.0的新訪客在點開始後，主選單已消失，卻沒有載入提示。冷瀏覽器同時請求約18MB離線包與必需戰場圖片；45秒仍無戰場控制，最後必需PNG約77秒才完成。另一個封鎖Service Worker的新訪客測試約36秒進入；兩輪網路條件不完全相同，僅作下載競爭證據，不當通用速度承諾。

另外驗證到一般滑鼠桌機可能回報maxTouchPoints=256，舊判定將它當手機並自動全螢幕。取消載入後立即重進，也會因Phaser未中止舊XHR，讓舊失敗錯誤污染新一輪。

## 修復

- 首訪不自動註冊或下載離線包，改為主選單明確點「下載離線版」。進入戰場會取消仍在進行的下載，保留已存在離線版。
- `play.html` 新入口能繞過舊worker的首頁快取；本版離線就緒需符合App0.21.1，缺件快取可在明確操作後補回。
- 戰場一開始就顯示DOM進度，有重新載入／返回；預載設定、素材或create失敗不再僅留下黑畫面。
- 取消與重試先中止捕捉的XHR及未完成圖片解碼，只接受當輪檔案事件；已完成的texture不移除。
- 主程式尚未下載時，HTML也有啟動提示與手動復原；只處理本遊戲scope與cacheprefix，保留localStorage、IndexedDB與使用者檔案。
- 手機限制依主要coarsepointer判定，觸控能力保留為獨立欄位。規則版本仍為0.18.1，未改戰鬥與存檔規則。

## 驗證

`npm run verify`通過：client119、server86、shared237、ops21，共463項。typecheck、18方向圖集檢查、建置、素材雜湊／授權、runtime預算、秘密掃描與production audit通過。

實際瀏覽器測試：慢PNG期間進度可見、返回即回選單；強制PNG失敗後重試恢復7操作鍵；舊503／新200與舊200／新503都不污染另一輪；預載拋錯後可重試，頁面RAF仍有效。啟動script另驗證module被阻擋、15秒仍載入、延後ready及同scope復原。PWA測到新訪客0SW請求／0註冊、40檔明確離線下載、真正斷網開局、取消背景下載、缺件修復及舊worker的play.html繞過。

測試紀錄見同資料夾、docs/evidence/entry與[entry-pwa-2026-10-01.json](../entry-pwa-2026-10-01.json)。公開站修復後需另看GitHub部署結果；本地334ms開局不冒稱公開網路速度。
