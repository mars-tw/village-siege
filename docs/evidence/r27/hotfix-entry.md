# 1.3.1 影片入口觸控修正驗收

公開版 1.3.0 在 844×390 顯示 PWA 工具列後，「下載離線版」會覆蓋「實玩影片」，正常觸控遭攔截。第一版修正雖移開 PWA 工具列，但 1366×600 與 390×844 又分別被首頁 eyebrow、標題覆蓋。

最終本機 hotfix snapshot 加入 header stacking，並在低高度桌機與直式窄畫面省略會重疊的裝飾 intro。驗收先等待 PWA 工具列與下載按鈕可見，再等一秒讓幾何穩定。

844×390、667×375、568×320、390×844、1366×600 五種 viewport 各有 18 個可見且啟用的按鈕；逐一以中心點 `elementFromPoint` 檢查，全部命中按鈕本身。實玩影片入口高度均為 44 CSS px，與 PWA 工具列重疊面積均為 0，頁面沒有水平溢出。開始戰役按鈕保持 50–58 px 且可點。

正常觸控可開啟及關閉播放器；影片實際解碼 960×540 並播放前進。離線版下載由正常按鈕啟動並完成為「離線版已備妥」；下載太快，介面沒有出現可操作的取消階段。下載完成後「實玩影片」中心仍命中自身且可再次正常開啟。

證據：`hotfix-entry.json`、`hotfix-entry-844x390.png`。
