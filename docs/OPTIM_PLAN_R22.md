# R22：人物、地圖與真正可玩戰場重製

2026-10-01。這輪直接替換實際遊戲畫面，不以入口插畫或計畫書當作遊戲完成。

## 本輪合同

- 32×24開闊地圖：西／東家園、可建造與集結空間、兩條至少三格寬的進軍路線、可探索的資源與側翼中立營地。開局不再是整圈城牆與塔樓。
- 新人物為統一半寫實中世紀4.5頭身；工匠有工作服、工具與工作影格，與軍隊分開。優先重做工匠、戰士、持盾槍衛、弓箭手六方向真動作；其餘兵種原有單向合同明列，不假稱六方向完成。
- 同畫風的點陣地表、樹叢、石礦與田地；不得SVG，不用靜態概念圖代替可走可建的地圖。
- 預設不把名稱、資源數與血量全部貼在場上。選取／滑過才顯示必要資料，受傷可顯示血條；桌機資源、目標和提示不重疊。
- 保留共享權威規則、迷霧、成本、人口與真技能。新尺寸／開局改動會升級rules，舊版本存檔不能偷改。
- 首次開局依然優先戰場素材，有進度／重試／返回；新增素材必須裁切、清理alpha、對齊腳底、壓縮、登記來源與雜湊。

## 交付閘門

1. 經濟→施工→產兵→混編→探索→交戰→合法勝利→結果與再戰，至少一局公開指令實跑，不能改state讓它贏。
2. 新出生點可通向開放家園，資源不堵生產出口；玩家與AI都走同規則。
3. 三地圖、迷霧與多人投影回歸、原有動畫validator、素材／秘密／授權、正式建置與runtime預算通過。
4. 戰場桌機／手機實際操作與before／after圖保存。真機與商店App沒有驗證就明列。
5. 完成後依既有授權更新mars-tw公開原型；後續未完成素材不能冒稱完整遊戲。
