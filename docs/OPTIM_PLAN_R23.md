# R23：施工中斷後接續

2026-10-01。範圍為使用者回報的施工中斷缺陷，沿用0.22既有角色、地圖與介面美術。

- 工匠從工地A轉至B後，A保留進度；選工匠點A可接續，選取工地亦提供「繼續施工」。
- 接續不重建物件、不重扣費、不重置血量；完成建築的修復與卸貨維持原行為。
- 自動派工優先可到達的閒置工匠，不自行中斷其他工地；手動指定工匠仍可換工。
- 保留rules0.19.0、network4與persistence/1；以更新前0.22.0真實測試fixture核對舊存檔與重播雜湊。
- 單機與線上入口同步，權限、死亡、不可達目標由shared規則判定。
- 八面向沿用R22已交付基準；本輪只修改施工選單、指令與工作動畫切換，不生成新美術，不更動地圖、戰鬥或付費成本。
- 驗收：A→B→A兩工地完成與成本測試、實際瀏覽器點擊接續、七格指令列可達、完整CI與正式包檢查。發布app0.22.1後驗證公開入口。
